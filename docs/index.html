【单选题】
在网络安全职业道德体系中，职业道德“基本要求”的核心在于调和“保护社会公共利益”“恪守对雇主的忠诚”与“维护行业专业形象”之间的潜在冲突。某金融科技公司安全管理员发现雇主在未充分告知用户的情况下将包含身份证和银行卡信息的数据库共享给第三方征信机构“联合建模”。公司法务认为该行为在已签署的数据共享协议下“技术合规”。根据国际公认的职业道德准则及我国相关法律精神，最准确的论断是（）。
A.法务部门出具的数据共享合规意见代表了企业内部对法律风险的权威判断，安全管理员在评估该意见的合理性后，仍应以法务结论作为行动的主要依据；若后续监管调查认定违规，法务部门将承担主要责任，安全管理员的职业风险相对较低
B.职业道德中的“恪守保密义务”属于相对义务，在涉及重大公共安全风险且雇主拒绝配合修复时，可向特定监管机构进行最小必要范围的信息披露——但应先通过内部合规渠道逐级反映并给予雇主合理的纠正期限
C.“诚实守信”不仅要求不伪造日志数据，也要求安全管理员对发现的可疑数据共享行为予以关注，但该关注应优先通过内部非正式沟通向直接上级提示，并在业务项目结束后补充书面记录，以避免干扰正常业务进程——这种做法在行业实践中被视为兼顾忠诚与审慎的常见方式
D.依据网络安全岗位的常规职责划分，个人信息保护的合规性判定通常归属于数据保护官和法务部门，安全管理员的主要职责聚焦于系统安全防护；若安全管理员对共享行为有疑虑，可建议法务部门重新评估，但在法务部门未明确回应前，可暂按现行流程推进，后续再根据评估结果调整操作
